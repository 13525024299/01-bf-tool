# 奇怪的书 · Brainfuck 解释器与三页解答

《2026 纳新笔试题》第七题「奇怪的书」的可运行答案。
一道题给了三种纸带程序（第一页、第二页），并让你自己写一个（第三页）。
为了不靠"肉眼看符号推演"出错，这里直接写了一个 8 关键字的 Brainfuck
解释器，把三页程序真正跑一遍，用输出反证推导。

## 目录结构

```
01-bf-tool/
├── README.md
├── .gitignore
├── src/
│   ├── bf.py          # 解释器本体（纸带、指针、括号配对跳转）
│   └── answers.py     # 三页任务的机器验证脚本
├── tests/
│   └── test_bf.py     # 单元测试
└── res/
    └── sample.bf      # 一份示例程序（打印 "HI"）
```

## 快速开始

```bash
# 跑三页答案（会打印每一步的输入输出与 ASCII 十进制值）
python src/answers.py

# 用解释器执行任意 .bf 文件
python src/bf.py res/sample.bf

# 带输入执行
python src/bf.py res/sample.bf "AB"

# 单元测试
python -m unittest discover -s tests -v
```

## 解释器的几个实现细节

1. **只认 8 个关键字**：`+-<>[].,`，其余字符（空格、换行、中文注释）全部过滤，
   所以题目里"一行一个符号"的排版可以直接粘贴运行。
2. **8 位无符号单元**：`+` 到 255 再加回到 0，`-` 到 0 再减变成 255，与题目
   "0–255（超出范围就溢出）"一致。
3. **括号配对**：先用栈把每个 `[` 和 `]` 的跳转目标算好存成字典，运行时 O(1)
   跳转，而不是每次循环重新扫一遍源码。
4. **纸带扩容**：指针越过右端时自动扩容，左端不允许越界（会抛 `IndexError`）。

## 三页的结论

| 页 | 程序做了什么 | 结果 |
| --- | --- | --- |
| 第一页 | 读入一个字符，循环把它的 ASCII 值累加到右边单元，再减 1 输出 | 输出 = 输入的 ASCII 值减 1，如 `A`(65) → `@`(64) |
| 第二页 | 外层循环 10 次，每次给右边两格各加 8，得到 80、80，再把第一格减 1 | 输出 `OP`，即 79、80 |
| 第三页 | 读两个字符，把第一个的 ASCII 值加到第二个上，输出和 | 输出两字符 ASCII 值之和，超过 255 回绕 |

详细推导见答卷正文。
